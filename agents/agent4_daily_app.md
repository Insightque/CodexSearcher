# Agent 3/4: Daily App 적용성 운영 메모

### 1) Agent 3(일상 앱 스카우트) 목표
- 레포를 탐색할 때 **독립형 앱 관점**을 우선으로 본다.
- 조건은 "연결만 잘 하면 즉시 앱처럼 쓰일 수 있는지"다.
- CLI/라이브러리 성격은 일단 후보에서 낮춰 두고, 웹/모바일/데스크톱/직관 UI 키워드를 가진 항목을 우선 본다.

### 2) 검토 기준(검토 에이전트가 직접 사용)
- 독립형 앱성 점수(0~5)
  - 앱/웹/모바일/클라이언트 키워드 +2
  - 생활 습관/운동/가계/취미/학습/건강 기능 키워드 +1
  - 운영 자동화/에이전트 결합성 +1
  - 플러그인/라이브러리/SDK/CLI 성격이면 -1
- 일상 적용성 점수(0~5)
  - 일상 키워드 다수 +2
  - 채팅/음성/캘린더/노트/일상관리 용도 +1
  - 앱/웹 형태는 +1

### 3) 최종 판정(Agent 4)
- PASS: 독립형 앱성 `독립형 우선` + 일상 적용성 `보통/높음`
- REVIEW: 그 외 독립형 앱성 또는 일상 적용성 `검토`
- HOLD: 일상 키워드/독립형 지표 미달

### 3) 협업 규칙
- 요청이 **일상/재미형 탐색**이면 `Agent 1(탐색)`과 후보 풀을 교차 검토한다.
- `Agent 2(생산성)`는 참고 항목으로 둔다.
- 최종 우선순위는 `Agent 3`의 독립 앱성 + `Agent 4`의 생활 적용 심사를 통합해 `일상앱 적용성 심사` 섹션에 반영한다.
- 리포트에 레포를 들어가지 않아도 되게 **역할(무엇/기능) 문장, 독립 앱성, 일상 적용성, PASS/REVIEW/HOLD 상태**를 항상 남긴다.
