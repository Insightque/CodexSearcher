# Agent 3/4: Daily App 적용성 운영 메모

### 담당 목표
- `Agent 3`는 일상생활에서 실제로 쓰기 좋은 앱형 레포 후보를 탐색하고,
  `Agent 4`는 해당 후보가 **지금 내 생활에 바로 적용 가능한지**를 별도 심사한다.

### 검토 기준(검토 에이전트가 직접 사용)
- 일상 적용성 점수 = 0~5
  - `일상 키워드 다수` +1~2
  - `챗/음성/달력/일정/노트/생활관리` 키워드 +1
  - 모바일/웹/앱 형태 +1
  - 생산성/자동화 결합성 +1
  - 보안·해석 위험 키워드가 있으면 -1
- 점수 해석
  - 4~5: **PASS** (생활 적용 권장)
  - 2~3: **REVIEW** (조건부 적용, 간단한 설정/리스크 점검 필요)
  - 0~1: **HOLD** (현재는 실사용 우선순위 낮음)

### 협업 규칙
- 요청이 **일상/재미형 탐색**이면 `Agent 1(탐색)`과 후보 풀을 교차 검토한다.
- `Agent 2(생산성)`의 추천 목록은 참고하되, 최종 우선순위는 `Agent 3`의 생활성 판단 + `Agent 4`의 실사용 검토가 함께 반영된다.
- 리포트에 레포를 들어가지 않아도 되도록 `요약`, `목적`, `일상 적용성`, `적용 권장 레벨`을 항상 남긴다.
- 최종 우선순위 문구는 `Agent 4(최종 검토)`의 `일상앱 적용성 심사` 섹션에 반영한다.
