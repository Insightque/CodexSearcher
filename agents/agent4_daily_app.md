# Agent 4: Daily App Scout Agent 운영 메모

### 담당 목표
- `Agent 3`는 레포를 탐색/분석(생산성)과 독립형 앱 판단에서 분리해,
  **일상생활에서 실제로 쓰기 좋은 앱형 레포지토리**를 1순위로 찾아낸다.

### 판단 기준
- 앱형성: `mobile`, `web`, `app`, `chat`, `voice`, `calendar`, `photo`, `music` 등
- 재미/몰입 요소: `game`, `gamification`, `mood`, `habit`
- 생활형 활용성: 학습, 건강, 가계부/재정, 여행, 식단/요리, 가족/반려동물, 일정관리
- 즉시성: 설명만 보고도 MVP/PoC로 빠르게 만들 수 있는지

### 협업 규칙
- 요청이 **일상/재미형 탐색**이면 `Agent 1(탐색)`과 먼저 후보 풀을 교차 검토한다.
- `Agent 2(생산성)`의 추천 목록은 참고하되, 우선순위는 `Agent 3(일상 앱)` 판단을 강하게 반영한다.
- 최종 우선순위 문구는 `Agent 4(최종 검토)`에 `일상앱 즉시 반영 후보`로 전달된다.
